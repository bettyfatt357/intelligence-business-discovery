ARCHITECTURAL PRINCIPLES
═════════════════════════════════════════════════════════════════════════

1. Storage Agnostic
   ├─ No Redis, Supabase, database
   ├─ No filesystem operations
   └─ Works with ANY backend

2. Infrastructure Independent
   ├─ No HTTP requests
   ├─ No external dependencies
   └─ Portable to any runtime

3. Plugin Architecture
   ├─ 18 deobfuscation methods
   ├─ 6 company detection sources
   ├─ Extensible pattern matching
   └─ Add new methods without rewrites

4. Evidence-Based
   ├─ All findings trackable
   ├─ Evidence shows WHERE and HOW
   ├─ Full audit trail
   └─ Verification enabled

5. Immutable Records
   ├─ Discovery captured at search time
   ├─ Never modified during processing
   └─ Complete reproducibility

6. Type-Safe
   ├─ Full TypeScript
   ├─ All interfaces exported
   ├─ No 'any' types
   └─ Type inference throughout

7. Modular
   ├─ Clear separation of concerns
   ├─ Single responsibility
   ├─ Easy to maintain
   └─ Simple to extend
